Download the package

Your download has started. Install it with the commands below.

  1. Install pipx once: python3 -m pip install --user pipx, then python3 -m pipx ensurepath.
  2. Install localagent: pipx install ~/Downloads/{{wheel_name}}
  3. Run the guided setup: localagent setup — then localagent in any project folder.

Requirements

What your computer needs

  • SystemWindows 10 or 11 (64-bit) with the zip; macOS or Linux with Python 3.10+.
  • Online modelsAn internet connection and a key — Gemini's is free. Nothing else.
  • Local modelAbout 6 GB of free memory and 5 GB of disk for the 8B model; 8 GB computers get the 4B one.
  • OptionalDocker Desktop, to run the agent's code in a sealed box. A graphics card makes local models faster.
