Why localagent

Built to be trusted with your code

An agent that edits files and runs programs has to be careful. These are the rules it never breaks.

  • {{test_count}}automated tests on every change
  • {{provider_count}}online services, plus any compatible address
  • {{server_count}}local model servers it finds
  • 0dependencies — only Python itself

Online and offline

An online model answers while you are connected. When the connection drops, a model on your computer takes over by itself — in the middle of a conversation — and the online model returns with the internet.

Checked before it is kept

Every file it writes is checked by the language's own tools — Python, JavaScript, TypeScript, Go, Rust, C/C++ and more. Broken code is rolled back byte for byte, and the errors go back to the model to fix.

Safe by default

Nothing runs without your approval unless your own rules allow it. Code can run in a sealed Docker box with no network, and /undo takes a change back without touching your own edits.

Free to run

Gemini's free key, or a free model on your own computer. It is built to finish in as few model calls as possible: a question in one or two, a small fix in about three.

Works the way you expect

Plans you approve first, a live checklist, a diff of every edit, /undo, /resume, project notes, permission rules, hooks, MCP tool servers and your own slash commands.

Private when it matters

In offline mode nothing leaves your computer. A local model listens only on your own machine and is stopped when you are done.

How a change is made

Every edit passes the same checks

The model can only ask to read, write or run. The program checks every request — and a write that breaks something never reaches your project.

  1. You ask“The tests fail — find the bug and fix it.”
  2. It readsonly the files it needs, inside your project folder
  3. It writesthe smallest edit, keeping your line endings and encoding
  4. It checkssyntax and lint with the language's own tools
  5. It testswith your project's test tool, after your approval
  6. You decideyou see every diff; /undo puts it back

Questions

Good to know

Is it really free?

Yes. The program is free and open source (MIT license). Gemini has a free daily quota, and a local model costs nothing at all. Paid services such as OpenAI or Anthropic bill you for what you use, at their prices.

Does my code leave my computer?

In offline mode, never. Online, the parts of your project the agent reads are sent to the service you chose, under that service's terms — on Gemini's free tier Google may use them to improve its products. Use offline mode for private code.

What do I need for a local model?

About 6 GB of free memory for the recommended 8B model (computers with 8 GB get the 4B one). The setup downloads llama.cpp and the model; the agent starts the model when needed and stops it when you leave. If you already run Ollama or LM Studio, it simply uses that.

Which languages does it check?

It can read and edit any text file. It checks Python, JavaScript, TypeScript, Go, Rust, C, C++, PHP, Ruby, shell, PowerShell, JSON, TOML and YAML before keeping them, and runs tests with pytest, unittest, npm, go or cargo.

Is it safe to let an AI run code?

Nothing runs without your approval unless one of your own rules allows it. With Docker, code runs in a sealed container that sees only your project and has no internet. You see a diff of every edit, and can undo it.

Can I change my mind later?

Any time: run localagent setup again, or switch for one run with localagent --provider groq or localagent --offline. localagent --doctor checks everything.
