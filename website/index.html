Built to be trusted with your code

An agent that edits files and runs programs has to be careful. These are the rules it follows.

Online and offline

An online model answers while you are connected. When the connection drops, a model on your computer takes over — by itself, in the middle of a conversation — and the online model returns when the internet does.

Verified before it is kept

Every file it writes is checked by the language's own tools — Python, JavaScript, TypeScript, Go, Rust, C/C++ and more. Broken code is rolled back byte for byte, and the errors go back to the model to fix.

Safe by default

Nothing runs without your approval unless your own rules allow it. Code can run in a sealed Docker box with no network. /undo takes a change back and never touches your own edits.

Free to run

Gemini's free key, or a free model on your own computer. It is built to finish tasks in as few model calls as possible: a question in one call, a small fix in about three.

Works the way you expect

Plans you approve first, a live checklist, a diff of every edit, /undo, /resume, project notes, permission rules, hooks, MCP tool servers and your own slash commands.

Private when it matters

In offline mode nothing leaves your computer. A local model listens only on your own machine and is stopped when you are done.

How it works

  1. You ask. “The tests fail — find the bug and fix it.” In any project folder, in plain words.
  2. It works with tools. The model can only ask to read, edit or run — the program checks every request, verifies every write and asks you before anything runs.
  3. You stay in control. You see each diff as it happens, and /undo puts the last change back.

Online, offline, or automatic

Switch at any time with /model offline, /model online or /model auto — the conversation and your files stay.

Install

Windows recommended

  1. Download {{zip_name}} ({{zip_size}}).
  2. Unzip it somewhere permanent, for example C:\Tools\localagent.
  3. Double-click install.cmd: it adds the folder to your PATH and starts the guided setup.
  4. Open a new terminal in a project folder and type localagent.

Python is included; nothing else needs installing.

Linux, macOS, or any Python 3.10+

Download the wheel ({{wheel_size}}), then:

pipx install {{wheel_name}}
localagent setup

No pipx? python3 -m pip install --user {{wheel_name}} works too.

Check a download before you run it — on Windows certutil -hashfile {{zip_name}} SHA256, elsewhere sha256sum -c SHA256SUMS.txt — and compare with SHA256SUMS.txt.

Questions

Is it really free?

Yes. The program is free and open source (MIT license). Gemini has a free daily quota, and a local model costs nothing at all. Paid services such as OpenAI or Anthropic bill you for what you use, at their prices.

Does my code leave my computer?

In offline mode, never. Online, the parts of your project the agent reads are sent to the service you chose, under that service's terms — on Gemini's free tier Google may use them to improve its products. Use offline mode for private code.

What do I need for a local model?

About 6 GB of free memory for the recommended 8B model (computers with 8 GB get a smaller one). The setup downloads llama.cpp and the model; the agent starts the model when needed and stops it when you leave. If you already run Ollama or LM Studio, it simply uses that.

Which languages does it work with?

It can read and edit any text file. It checks Python, JavaScript, TypeScript, Go, Rust, C, C++, PHP, Ruby, shell, PowerShell, JSON, TOML and YAML before keeping them, and runs tests with pytest, unittest, npm, go or cargo.

Is it safe to let an AI run code?

Nothing runs without your approval unless one of your own rules allows it. With Docker, code runs in a sealed container that sees only your project and has no internet. You see a diff of every edit, and can undo it.

Can I change my mind later?

Any time: run localagent setup again, or switch for one run with localagent --provider groq or localagent --offline. localagent --doctor checks everything.
